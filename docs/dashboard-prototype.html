设计说明
  • 显示的是整台机器：oMLX 最多 8 条流同时跑，所有数字要么是所有流的合计，要么是这一轮的累计。
  • 流指示点：状态条最左边，点数等于引擎的并发上限（oMLX 8 个），从左到右是解码中（绿）、预填充中（琥珀）、空着（灰）；有排队时后面写“+2”。
  • 状态：有任何一条流在解码就是“解码中”；没有解码、有预填充才是“预填充中”；全部结束才是“完成”。
  • 解码：仪表盘是所有流的合计速度（最近 2.5 秒平均）。刻度 0 / 25 / 50 / 100 / 200 / 300，前密后疏。多条流时状态条写“解码 n · 预填充 n · 排队 n”。
  • 预填充（新）：仪表盘是实时预填充速度（琥珀色，刻度 0–3K），下面是进度条“已算 / 提示”。单个请求时右侧是“缓存命中 / 已等待 / 内存”；一轮模式下右侧不变，已用时、缓存命中、剩余时间写在状态条。
  • 一轮：上一个请求结束后 60 秒内来的请求算同一轮；并发的请求一定在同一轮。本轮请求 ≥ 2 时右侧固定为“本轮请求 / 累计输出 / 本轮平均”。本轮没出现过并发时平均值是引擎给的精确值（带“精确”）；出现过并发时改为“本轮输出 ÷ 有流在解码的时长”，和仪表盘的合计速度一致。
  • 完成：所有流都结束才出现，停 4 秒。单个请求显示引擎的精确成绩；一轮模式显示本轮统计（灰色）。第三格：Spark 版是“接受率”；oMLX 没有推测解码，改成“首字”，状态条右边就不再重复写首字。
  • 空闲 = 今日统计：今日费用（按各模型自己填的 API 单价折算，货币在费用页里选：美元 / 人民币）、今日输入、输出、请求数。按菜单里选的时区（跟随系统 / 北京时间 / 太平洋时间）0 点清零，圆圈下面写日期和时区名。一轮中间的空隙不切到今日统计，一轮结束后才切。
  • 上下文条：显示占用最大的那条流。占到 80% 变琥珀色、95% 变红色。
  • 模型加载中（新）：oMLX 按需加载模型，请求来了才加载、闲置久了会卸载。加载期间显示已用时，进度条按 oMLX 给的预计时间走（最多到 99%），请求在后面排着（“+1”）。
  • 费用单价（新）：每个模型一组，自己查了 API 价格在菜单栏的“费用单价…”里填，不带默认值。有的模型没填：主数字只算填了的，日期那行写“不含 n 个模型”；一个都没填：主数字是“—”，日期那行写“未填单价 · 在菜单栏里填”。
  • 货币（新）：费用页顶上选美元（默认）或人民币。单价按所选货币填；换货币只换符号和文字，数字不按汇率换算，已填的单价和历史都不动。空闲画面的标题写“今日费用 · 美元 / 人民币”，数字带 $ / ¥。
  • 引擎：在设置里选，这一版只有 oMLX。空闲和离线时模型名后面标出引擎名。预填充速度和进度是 oMLX 实报的。
  • 副屏截图（调试，新）：菜单栏新增一项，把副屏真实显示的内容截成 PNG（真实像素，不是重画）存到 ~/Library/Logs/TFPanel/ 并在 Finder 里定位，用于排查“画面数据对、屏幕显示不对”的问题；副屏未接时置灰。截屏用的是已弃用的 CG 老接口，实测 macOS 26 上不需要“屏幕录制”权限。
  • 数字：速度、内存这些还是 Spark 版的实测值，Mac Studio 到了用实测值替换。
  • 没有模拟的：空闲 30 分钟后画面调暗到 40%。
