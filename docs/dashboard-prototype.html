设计说明
  • 布局：左 2/3 为 270° 弧形仪表 + 主数字，右 1/3 为 3 个数据块，顶部一条状态条。四周留 12px。
  • 字号：主数字 96px；右侧数值 30px；标签 / 状态条 13–14px；刻度 12px（全场最小）。
  • 刻度非线性：0 / 25 / 50 / 100 / 150 / 200，低速段拉宽，30–190 tok/s 的常见区间都看得清。
  • 平滑：主数字 = 最近 2.5 秒内产出 token 数 ÷ 2.5 秒（开头不足 2.5 秒时按已用时间算，最少按 0.5 秒）；弧线和数字再以约 0.4 秒时间常数缓动。
  • 峰值：只统计解码开始 1 秒之后的平滑值，避免开头的假尖峰。
  • 预填充：本版本拿不到进度和提示长度，所以只显示已用秒数 + 来回扫动的弧段，不显示百分比或剩余时间。超过 1.5 秒时状态条提示「提示较长」。
  • 解码：右侧为 输出 / 平均 / 峰值。「平均」= 首字之后的输出 tokens ÷ 首字之后经过的时间，和引擎最终 tok/s 同一算法，会逐渐收敛到完成时的精确值。首字时间放在状态条。第 1 层解码中拿不到接受率，所以不显示。
  • 完成：大数字是引擎给出的本次平均速度（精确值），带「精确」标记；4 秒后淡回空闲（手动选择时停留）。
  • 空闲：主数字变灰，显示上一次的最终速度；弧线上留一个小点标出上次位置。
